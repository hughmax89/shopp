"SHOPP" by Hugo Agüero

Is a app native in Android with Kotlin, it desinging in MVVM, clean architecture and principles SOLID.

And I use the next technologies:

Compose -> UI
Coroutines -> threads
Flow -> states in UI/ViewModel
Dagger Hilt -> Dependency Injeccion
Room -> DataBase
Retrofit -> API
Authentication -> Firebase
GITHUB -> Respository

I use information from 2 apis:

In the login I get data from Country A from API(https://fakestoreapi.com/),
and I get informacion from Country B from API(https://fakeapi.platzi.com/en/rest/products/)
